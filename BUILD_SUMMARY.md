## 🆘 Troubleshooting

### Common Issues

**Q: Images not showing?**
A: Check file path in HTML, verify image exists, try full URL

**Q: Form not working?**
A: Connect to email service (Formspree recommended), check console

**Q: Theme not saving?**
A: Enable localStorage, clear cache, check browser privacy settings

**Q: Colors look wrong?**
A: Check CSS variables, verify color hex codes, clear cache

**Q: Mobile layout broken?**
A: Check viewport meta tag, test in DevTools device mode
